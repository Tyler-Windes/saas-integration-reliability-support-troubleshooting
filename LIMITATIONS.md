# Limitations

- This is a synthetic local work sample. The services, accounts, events, traces, failures, and incident narratives are fictional and contain no personal data.
- The FastAPI services and SQLite stores are mocks, not replicas of a real CRM, support platform, customer environment, or production architecture.
- The API key is a local testing mechanism supplied through an environment variable. It is not a production authentication or secrets-management design.
- Retry, dead-letter, replay, mismatch, and reconciliation behavior is deterministic fault-injection evidence, not a production reliability, availability, or service-level result.
- The proof does not establish scale, load capacity, security posture, adoption, savings, customer impact, or operational performance.
- The Python reference orchestrator is the only executed workflow authority.
- n8n was not executed. The JSON workflow is an unexecuted structural draft and must not be treated as proof of n8n proficiency.
- No live endpoint, external SaaS account, customer system, or production data is required or represented.
